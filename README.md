# ME Bank CLI

A simple command-line banking application written in Python.

This is a personal learning project I'm building to practice Python,
Object-Oriented Programming, file handling, authentication, and
software architecture.

## Features

- Create an account
- Generate account numbers
- Hash PINs
- Login/authentication
- Check balance
- Deposit money
- Withdraw money
- Store account data locally

## Project Structure

- `main.py` — Runs the application and handles the menus
- `bank.py` — Handles banking operations and authentication
- `accounts.py` — Contains the `BankAccount` class
- `storage.py` — Handles saving and loading account data
- `utils.py` — Contains reusable utility functions
- `cli_handlers.py` — Handles user input and validation
